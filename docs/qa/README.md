# Контрольные изображения PDF

Это рендеры файлов, выгруженных из изолированного тестового API. Они не являются скриншотами веб-интерфейса. Имена и документы на них — тестовые.

- [Кассовая книга](cashbook.png).
- [Расходный документ](document.png).
- [Длинный отчёт: первая страница](long-report-first.png).
- [Длинный отчёт: последняя страница](long-report-last.png).

Проверены русский текст, переносы, таблицы, итоговые суммы и повтор заголовков. Для рендеринга использовался PDF.js с отключённым системным font-face в Node.js; текст рисуется из встроенных в PDF шрифтов. На длинном отчёте автоматически проверено наличие заголовков на каждой из восьми страниц. Первую и последнюю страницы просмотрели визуально.

Снимки веб-страниц не получены из-за ограничения инструмента браузерного управления. Дальнейшая ручная проверка перечислена в [отчёте](../interface-review.md).
