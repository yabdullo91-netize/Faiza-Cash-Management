# Учёт кассовых операций ООО «Фаиза»

Веб-приложение для регистрации черновиков кассовых операций, проведения, контроля отрицательных остатков, поиска и CSV-отчётов. Реализованы серверная авторизация с ролями, ротация refresh-токенов, аудит и кассы в нескольких валютах.

## Быстрый запуск

1. Скопируйте .env.example в .env.
2. Замените все значения change_this на уникальные секреты. JWT-ключ должен быть не короче 32 символов, пароль администратора — не менее 10 символов с буквами и цифрами.
3. Выполните: docker compose up --build
4. Откройте http://localhost:8080. Первый пользователь создаётся из SEED__ADMINLOGIN и SEED__ADMINPASSWORD; после первого входа пароль необходимо сменить.

Для локального запуска без Docker задайте переменные окружения ConnectionStrings__CashDb, Jwt__Key, Seed__AdminPassword и выполните dotnet run --project src/FaizaCash.Api.

## Роли

- admin — пользователи, кассы, валюты, начальные остатки;
- accountant — справочники, черновики, проведение и сторно;
- manager — просмотр аудита;
- auditor — просмотр аудита и журнала.

## Важные правила

- В остаток включаются только операции со статусом posted.
- Проведение блокирует строку кассы и не допускает отрицательный остаток даже для задней даты.
- Номер ПКО/РКО присваивается только при проведении в пределах транзакции.
- Черновики редактируются по версии; конфликт возвращает HTTP 409.
- Проведённая операция не редактируется и не удаляется. Сторно создаёт отдельный черновик противоположного типа.
- Все действия входа, пользователей, касс и операций попадают в аудит.

## Безопасность

Секреты не хранятся в репозитории: .env игнорируется Git. Access JWT живёт 15 минут; refresh-токен хранится только в HttpOnly, Secure, SameSite=Strict cookie и ротируется. Пароли защищены PBKDF2-SHA512 (600 000 итераций); вход с одной пары логин/IP ограничен после пяти неудач за 15 минут.

Перед production-развёртыванием поставьте TLS перед приложением, используйте отдельную роль PostgreSQL с минимальными правами и включите ежедневное резервное копирование. Пример: docker compose exec db pg_dump -U faiza_app faiza_cash > backup.sql
